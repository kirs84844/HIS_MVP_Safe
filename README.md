# HIS_MVP_Safe V6.4

Windows 7 32位 HIS 病程记录辅助工具。

- 患者范围支持全部、指定范围和跳过床位，按 HIS 列表逐行扫描并校验患者姓名。
- F8 全局暂停/继续，F9 在当前记录保存完成后安全终止。
- 补病史直接处理当前 HIS 窗口患者，不执行窗口标题或本地患者库匹配。
- 补病史支持 7天、14天、1个月、2个月和3个月间隔，生成时间不会超过运行时的系统时间。
- 补病史可选择1个普通模板固定重复，或选择3个普通模板依次循环。
- 病史名称默认“高一鸣主治医师查房记录”，支持修改或留空。
- 普通批量扫描使用床位初始定位、床位差修正和近距离单向逐行纠偏，并在写入前校验姓名和床号。
